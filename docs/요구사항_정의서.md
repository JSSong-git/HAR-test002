- Fact-Only: HAR에 존재하는 수치만 사용
- 결측(`-1`/부재) → 「측정 안 됨」, 0 보정 금지

- 점수/등급 없음

## 3. Diff 표기

| 기호 | 의미 |
|------|------|
| Δ | 이후 − 이전 (ms/bytes/count) |
| added / removed | 이후 전용 / 이전 전용 리소스 |
| grew / shrunk | 전송량 ≥20% 그리고 ≥50KiB 변화 |

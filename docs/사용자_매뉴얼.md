# HAR-test002 사용자 매뉴얼

## 웹 앱

```bash
pnpm install
pnpm --filter @har-analyzer/web dev
```

1. http://localhost:5173 접속
2. `.har` 파일 업로드 (로컬만 처리, 서버 전송 없음)
3. 회차 선택 후 **분석 결과 / 내보내기 / 요청 시간표 / 비교(Diff)** 탭 확인

### 옵션

| 옵션 | 설명 |
|------|------|
| 민감 헤더/쿠키 마스킹 | Authorization·Cookie·token 등 표시 경로에서 `***MASKED***` |
| 응답 본문 제외 분석 | `content.text` 제거 후 분석(대용량·메모리 완화) |
| 비교용 HAR | 두 번째 파일로 Diff(Δ onLoad/TTFB/전송량) |

### Core Web Vitals

WPT/Chrome HAR에 `_chromeUserTiming.*` 또는 `_LCP` 등이 있으면 관측값만 표시합니다.  
`fixtures/sample.har`처럼 확장 필드가 없는 파일은 「확장 필드 없음」으로 안내하며, 값을 추정하지 않습니다.

### 네트워크 뷰어

「네트워크 뷰어」탭은 Sauce Labs `network-viewer`를 사용합니다.  
선택 회차 HAR만 넘기며, 마스킹 토글이 켜져 있으면 민감 헤더/쿠키가 가려진 데이터를 표시합니다.  
(peer React 16 권장 라이브러리이나 React 19에서 탭 통합 검증됨.  
상단 Scatter 타임라인은 라이브러리 `payload.timings` null 접근 버그로 비활성화하고, 요청 표·워터폴·상세 패널은 사용합니다.)

### 내보내기

- 마크다운 복사·다운로드
- 단일 HTML 다운로드
- 인쇄 / PDF (브라우저 인쇄)

## CLI

```bash
pnpm --filter @har-analyzer/cli build
node packages/cli/dist/cli.cjs analyze ./fixtures/sample.har --max-ttfb 5000
```

예산 미달 시 exit code `1`. 자세한 플래그는 `docs/CI_성능예산.md` 참고.

## Chrome Extension MVP

1. `pnpm --filter @har-analyzer/chrome-ext build`
2. Chrome → 확장 프로그램 → 개발자 모드 → `packages/chrome-ext/dist` 로드
3. DevTools → **HAR Analyzer** 패널에서 HAR JSON 붙여넣기

## 해석 원칙

- 값이 `-1`이거나 없으면 **측정 안 됨** (0으로 보지 않음)
- 추측·외부 가설 문장은 보고서에 넣지 않음
